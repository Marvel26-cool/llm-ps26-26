# Math Word Problem Solver — PS26

**Roll No:** <26>
**PS26:** Solve math word problems step-by-step with Python arithmetic verification.

## What it does
- Takes a math word problem
- Uses Google Gemini LLM to solve step-by-step
- Verifies the answer's arithmetic with Python (sympy)
- Shows a green "verified" badge when the Python check matches

## Stack
Python 3.11 · Streamlit · google-genai SDK · sympy · python-dotenv

## How to run
1. `git clone https://github.com/<USERNAME>/llm-ps26-<26>.git`
2. `pip install -r requirements.txt`
3. Create `.env` with `GEMINI_API_KEY=your_key`
4. `python -m streamlit run app.py`
